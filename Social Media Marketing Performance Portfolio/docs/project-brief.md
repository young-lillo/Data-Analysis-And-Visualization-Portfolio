# Project Brief

## Project

Social Media Marketing Performance Portfolio

## Goal

Build an English-language analytics project that explains which content, platform, posting-time, regional, and promotion factors drive stronger social media performance.

## Audience

- Marketing managers
- Growth and content strategists
- Portfolio reviewers or hiring managers

## Selected Stack

- Storage and modeling: `Supabase`
- Interactive dashboard: `Metabase`
- Local validation stack: Dockerized `PostgreSQL + Metabase`

## Core Questions

1. Which platforms and post types drive the strongest engagement and views?
2. Which content categories perform best by region?
3. What days and hours maximize engagement?
4. Which hashtags improve impressions or clicks?
5. How does organic compare with sponsored content?
6. Which regions show stronger video or live-stream interest?

## Deliverables

- Reproducible prepared exports
- SQL load and analytics views
- Live local Metabase stack
- Dashboard builder script
- Project docs for preparation, visualization, and publish handoff
