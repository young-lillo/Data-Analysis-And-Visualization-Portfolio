# Project Brief

## Identity

- Slug: banking-transaction-data-analytics-challenge
- Context: Banking Data Analyst portfolio challenge focused on customer behavior, profitability, channel performance, branch geography, risk signals, and strategic recommendations for internal banking transaction records.
- Dataset: Excel workbook `Banking_Transactional_Dataset.xlsx`. Main sheet Banking Data has 20,000 transactions and 19 fields: transaction IDs, customer IDs, dates, transaction types, amounts, product category/subcategory, branch city/lat/long, channel, currency, credit-card fees, insurance fees, late payment amount, customer score, monthly income, customer segment, and recommended offer. Data Dictionary sheet documents 19 columns.
- Goals: Build an Advanced CRISP-DM Power BI banking analytics project answering customer segmentation, product popularity, credit-score relationships, transaction frequency/value, branch/city hotspots, channel usage, fee revenue drivers, high-fee customer groups, transactional friction, monthly/seasonal trends, offer alignment, and strategic roadmap recommendations.
